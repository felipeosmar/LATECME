# Add search input debouncing with visual feedback

## Overview

Implement debounced search with a visual typing indicator for all search/filter forms

## Rationale

Search forms like in material_list.html trigger on form submit, requiring manual button clicks. For better UX, debounced auto-search with visual feedback would reduce friction. The debounce function exists in app.js but isn't being used.
