# Add ARIA labels to icon-only action buttons

## Overview

Add descriptive aria-label attributes to all icon-only buttons and links in data tables and navigation

## Rationale

Action buttons in tables (view, edit, delete) use only icons without text or aria-labels. Screen readers announce these as 'button' or 'link' without context, making the interface inaccessible to visually impaired users
