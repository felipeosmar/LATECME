# Add Python linting and code quality configuration

## Overview

The project has no linting configuration files (flake8, pylint, mypy). Without automated code quality checks, inconsistent coding styles, unused imports, and type errors can accumulate over time.

## Rationale

Linting tools catch common bugs, enforce consistent code style, and improve code readability. They are especially valuable in team environments and CI/CD pipelines. The project already uses pyproject.toml which can host most linting configuration.
