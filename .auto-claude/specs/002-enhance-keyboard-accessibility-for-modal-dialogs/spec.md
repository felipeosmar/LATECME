# Enhance keyboard accessibility for modal dialogs

## Overview

Add proper focus trapping, focus restoration, and keyboard navigation to all Alpine.js modals

## Rationale

Current modals (like the movement modal in stock_list.html) lack focus trapping - users can tab out of the modal while it's open. This is both an accessibility issue (WCAG 2.1 Level A) and a usability problem
